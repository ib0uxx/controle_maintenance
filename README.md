## Comment lancer l'application :

1. Cloner le dépôt GitHub : `git clone https://github.com/ib0uxx/controle_maintenance.git`
2. Accéder au répertoire du projet : `cd controle_maintenance`
3. Installer python
4. Lancer l'application : `python src/main.py`

## Comment lancer les tests unitaires :
1. Accéder au répertoire du projet : `cd controle_maintenance`
2. Lancer les tests unitaires : `python -m unittest discover -s tests`


## La structure du projet :
Un dossier `src` contient le code source de l'application.
Un dossier `tests` contient les tests unitaires. 
Le fichier `README.md` fournit des instructions sur la façon de lancer l'application et les tests.
Le fichier `TMA.md` contient les spécifications fonctionnelles de l'application.
